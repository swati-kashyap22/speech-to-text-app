# EchoScript

Speak Naturally. Transcribe Instantly.

EchoScript is an AI-powered speech-to-text web application built using the MERN stack and Deepgram AI. Users can record or upload audio files, generate real-time transcriptions, and store transcription history in MongoDB Atlas.

---

## Features

- Real-time AI speech transcription
- Audio recording using microphone
- Audio file upload support
- MongoDB transcription history
- Delete transcription history
- Responsive modern UI
- AI-powered speech recognition using Deepgram
- MERN stack architecture

---

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Vite

### Backend
- Node.js
- Express.js
- Multer

### Database
- MongoDB Atlas
- Mongoose

### AI Integration
- Deepgram Speech-to-Text API
